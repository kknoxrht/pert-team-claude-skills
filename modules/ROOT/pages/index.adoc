== Welcome!

This repository serves as both a *working demonstration* and a *distribution package* for the Antora Progress Tracking feature. Navigate through the course modules and watch green checkmarks (✓) appear next to pages you've visited!

=== What is Progress Tracking?

Progress tracking adds visual indicators to your Antora course navigation, helping students:

* See which pages they've already visited (✓ checkmark appears)
* Track their learning progress through the course
* Resume where they left off across browser sessions

**Privacy-first:** All tracking happens client-side using browser localStorage. No data leaves the student's device.

== Installing Progress Tracking

There are two ways to add progress tracking to your courses:

=== Option 1: Clone This Repository

If you want to use this repository as a template for a new course:

[source,bash]
----
# 1. Clone this repository
git clone https://github.com/kknoxrht/pert-team-claude-skills.git my-new-course
cd my-new-course

# 2. Build and serve
npm install
npm run build
npm run serve
----

**What you get:**

* ✅ Progress tracking already installed and working
* ✅ Example course structure (replace with your content)
* ✅ All configuration files pre-configured
* ✅ UI bundle with progress tracking built-in

**Next steps:**

1. Replace the example modules (`claude-basics`, `skill-building`, `course-creation`) with your own content
2. Update `antora.yml` with your course title and navigation
3. Customize `antora-playbook.yml` if needed
4. Build and deploy!

=== Option 2: Use as Claude Code Skill (Recommended)

To add progress tracking to an *existing* Antora course using Claude Code:

[source,bash]
----
# 1. Install the skill in Claude Code
cd ~/.claude/skills/
git clone https://github.com/kknoxrht/pert-team-claude-skills.git
# Or copy just the skill folder:
cp -r https://github.com/kknoxrht/pert-team-claude-skills.git/skills/antora-progress-tracking ~/.claude/skills/

# 2. Navigate to your course
cd /path/to/your-antora-course

# 3. In Claude Code, run:
/add-progress-tracking
----

**What the skill does:**

1. ✅ Validates your Antora project structure
2. ✅ Detects if progress tracking is already installed (safe to re-run)
3. ✅ Warns if you have custom `nav-tree.hbs` overrides (backs them up)
4. ✅ Installs 6 files:
   * `supplemental-ui/partials/nav-tree.hbs` - Navigation template with progress markers
   * `supplemental-ui/js/progress-tracker.js` - Tracking logic (~150 lines)
   * `supplemental-ui/css/progress-tracker.css` - Checkmark styling
   * `supplemental-ui/partials/footer-scripts.hbs` - Script loader
   * `supplemental-ui/partials/head-styles.hbs` - CSS loader
   * `modules/appendix/pages/progress-tracking.adoc` - User documentation
5. ✅ Updates `modules/appendix/nav.adoc` to include documentation link
6. ✅ Rebuilds your course (`npm run build`)
7. ✅ Verifies installation

== How It Works

[source,mermaid]
----
graph LR
    A[User visits page] --> B[JavaScript reads URL]
    B --> C[Updates localStorage]
    C --> D[Scans navigation]
    D --> E[Shows ✓ for visited pages]
----

**Technical details:**

* **Storage:** Browser localStorage (key: `antora-course-progress`)
* **Data format:** JSON array of visited page URLs
* **Privacy:** All data stays on user's device
* **Compatibility:** Works with Antora 3.x supplemental-ui mechanism

== Uninstalling

To remove progress tracking from a course:

[source,bash]
----
cd /path/to/your-course

# In Claude Code:
/remove-progress-tracking
----

The uninstall skill will:

1. ✅ Detect installed version
2. ✅ Restore backup files (if they exist)
3. ✅ Remove progress tracking files
4. ✅ Update navigation
5. ✅ Rebuild and verify

== Customization

=== Change Checkmark Icon

Edit `supplemental-ui/partials/nav-tree.hbs`:

[source,handlebars]
----
<!-- Change from: -->
<span class="nav-progress-mark" aria-hidden="true">✓</span>

<!-- To your icon: -->
<span class="nav-progress-mark" aria-hidden="true">★</span>
----

**Icon options:** ✓ (checkmark), ✔ (heavy), ★ (star), 🎯 (target), 🟢 (green circle)

=== Change Colors

Edit `supplemental-ui/css/progress-tracker.css`:

[source,css]
----
.nav-progress-mark {
  color: #00a86b; /* Green - change to your color */
}

/* Dark mode */
@media (prefers-color-scheme: dark) {
  .nav-progress-mark {
    color: #4ade80; /* Light green */
  }
}
----

=== Clear Progress (Testing)

Open browser console (F12) and run:

[source,javascript]
----
clearCourseProgress()
----

This removes all progress data from localStorage and reloads the page.

== Troubleshooting

=== Checkmarks Not Showing

1. **Check browser console** (F12 → Console) for JavaScript errors
2. **Verify localStorage** (F12 → Application → Local Storage)
   * Should see key: `antora-course-progress`
   * Value: JSON array like `["/path/page1.html", "/path/page2.html"]`
3. **Inspect navigation links** (F12 → Elements)
   * Links should have `data-progress-path` attribute
   * Should contain `<span class="nav-progress-mark">✓</span>`

=== Build Errors

Clear cache and rebuild:

[source,bash]
----
rm -rf build .cache
npm run build
----

=== Custom Overrides Conflict

If you have custom `nav-tree.hbs` or other partials:

1. The skill warns before overwriting
2. Backups are created as `*.backup`
3. Merge your customizations manually if needed
