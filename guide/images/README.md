# Images Directory

## Red Hat Logo

Place the Red Hat logo here:

**Filename:** `red-hat-logo.svg`

**Recommended specs:**
- Format: SVG (vector)
- Height: 50px (will be scaled)
- Color: White or Red Hat red (#EE0000)

**Where to get it:**
- Red Hat Brand Center: https://www.redhat.com/en/about/brand/standards
- Internal brand resources
- Ask your design team

**Note:** The guide will work without the logo - it will simply be hidden if the file is not found.
