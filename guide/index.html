🚀 Installation Steps

1

Clone the Skill Repository

Open your terminal and run:

cd ~/.claude/skills/
git clone https://github.com/YOUR-USERNAME/antora-progress-tracking-skill.git
Note: This is a one-time setup. You only need to clone the skill once.
2

Navigate to Your Course

Go to the Antora course directory where you want to add progress tracking:

cd /path/to/your-antora-course

Example:

cd ~/Documents/GitHub/rhoai3-maas
3

Run the Installation Skill

Start Claude Code and run the skill:

claude

Then in Claude Code, type:

/add-progress-tracking
What happens: Claude will validate your course, install files, update navigation, and rebuild your site.
4

Test Locally

Start your local server:

npm run serve

Open your browser and:

  1. Navigate to a few different pages
  2. Refresh the browser
  3. Check the navigation sidebar for green checkmarks ✓
5

Commit and Deploy

If everything looks good, commit your changes:

git add -A
git commit -m "Add progress tracking v1.0"
git push origin main
GitHub Pages: Your changes will deploy automatically if GitHub Pages is enabled.

💡 How to Use

For Students

Progress tracking works automatically:

  • Visit course pages normally
  • Checkmarks appear next to visited pages
  • Progress persists across browser sessions
  • No login or registration required

Customizing the Checkmark

Change the checkmark icon:

Edit: supplemental-ui/partials/nav-tree.hbs

Find line 12:
<span class="nav-progress-mark">✓</span>

Change to:
<span class="nav-progress-mark">★</span>

Other icon options: ✔ ★ 🎯 🟢

Clearing Progress (Testing)

To reset progress during testing:

  1. Open browser DevTools (F12)
  2. Go to Console tab
  3. Type: clearCourseProgress()
  4. Press Enter

Page will reload with all checkmarks cleared.

Uninstalling

To remove progress tracking:

cd /path/to/your-course

claude
/remove-progress-tracking

The skill will restore backups and remove all files.

🔧 Troubleshooting

Checkmarks not showing +
  1. Check browser console for errors (F12 → Console)
  2. Verify files exist: 
    ls build/site/_/js/progress-tracker.js
ls build/site/_/css/progress-tracker.css
  3. Check localStorage is enabled (not in private browsing)
  4. Rebuild the site: 
    rm -rf build .cache
npm run build
Build fails after installation +

Clear cache and rebuild:

rm -rf build .cache
npm run build

If errors persist, check for pre-existing issues unrelated to progress tracking.

Skill not found +

Verify the skill is in the correct location:

ls ~/.claude/skills/antora-progress-tracking-skill/skill.md

If not found, re-clone the repository:

cd ~/.claude/skills/
git clone https://github.com/YOUR-USERNAME/antora-progress-tracking-skill.git
Custom overrides detected +

The skill detected existing custom files. Options:

  1. Allow backup: Say "yes" - skill will backup your files to *.backup
  2. Merge manually: After installation, compare: 
    diff supplemental-ui/partials/nav-tree.hbs.backup \
     supplemental-ui/partials/nav-tree.hbs
